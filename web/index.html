    From your question to a cited answer.

    A retrieval-augmented pipeline over a saved copy of ten ISSO pages. The model only sees the passages retrieval hands it, and must cite one of them.

    1. POST /chat

      Your question

      Trimmed and capped at 1,000 characters. Each visitor gets 5 questions a minute and 50 a day.

    2. embed_query()

      Embed

      The question becomes a 768-number vector with gemini-embedding-001, the same model that embedded the pages.

    3. retrieve()

      Retrieve

      Cosine similarity against 182 passages cut from the ten pages. The closest 3 go forward.

    4. answer()

      Generate

      gemini-3.1-flash-lite answers using only those 3 passages, and says so when they don’t cover the question.

    5. More info

      Cite

      The answer ends with the heading and link of the passage it used, copied from the source, never invented.

    Keeping it current

    A monitor script compares the saved pages with the live site: the sitemap’s last-modified date first, then a hash of the page body, then its layout blocks and how much text the parser captured. Pages that leave the sitemap are archived and never retrieved again.

    Stack

    Python and FastAPI on Google Cloud Run, Gemini for embeddings and answers, brute-force cosine search in NumPy. This page is plain HTML, CSS and JavaScript.
